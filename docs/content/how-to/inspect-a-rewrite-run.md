## Write the log

Pass `--log FILE` to write the log to a file, or `--log-stdout` to print it on standard output. With `--log-stdout`
and no `--output`, the log comes first and the graph follows it. The log is written when the run ends and also when a
rewrite fails, so a failed run still leaves a record of every step before the failure.
The fields are listed in [Log format]({{< relref "/reference/log-format" >}}).

## List the rewrites that ran

```shell
jq -r '.[] | select(.type == "Graphiti.EntryType.rewrite") | .name' log.json
```

Count them by name:

```shell
jq -r '.[] | select(.type == "Graphiti.EntryType.rewrite") | .name' log.json | sort | uniq -c
```

Names that start with `rev-` are undo steps generated by `reverseRewrites`.

## Find the step that failed

`Rewrite.run'` adds a log entry of type `Graphiti.EntryType.debug` as soon as a pattern matches, and turns it into a
`Graphiti.EntryType.rewrite` entry only when the rewrite finishes. If a rewrite fails after matching, the last entry is
therefore a debug entry with the rewrite's name, its input graph and the matched nodes:

```shell
jq '.[-1] | {type, name, matched_subgraph, debug}' log.json
```

The `input_graph` and `output_graph` fields hold Lean `repr` output for an `ExprHigh` value, not DOT. Paste one into a
Lean file as a term if you want to replay the rewrite on it.

## See which nodes a rewrite replaced

```shell
jq '.[] | select(.name == "pure-seq-comp") | {matched_subgraph, renamed_input_nodes, new_output_nodes}' log.json
```

`renamed_input_nodes` maps each matched node to its new name, or to `null` if the rewrite removed it.
`new_output_nodes` lists nodes the rewrite created.

## Look at Graphiti's view of the graph

- `--no-dynamatic-dot` prints the graph with Graphiti's own DOT printer and skips the conversion back to Dynamatic.
  Types appear as `(name, number)` pairs.
- `--parse-only` stops after parsing. Combine it with `--no-dynamatic-dot` to check what the parser and
  `dynamatic-to-graphiti.py` made of an input file.
- `--no-python` skips both conversion scripts. Use it when the input is already in Graphiti's format.

## Add your own log entries

Inside a rewrite pipeline written in Lean, record intermediate values with `addRuntimeEntry`:

```lean
addRuntimeEntry <| {RuntimeEntry.debugEntry (toString g) with name := "after-normalisation"}
```

The entry appears in the log with type `Graphiti.EntryType.debug`. `reverseRewrites` skips debug entries, so they do
not affect undo.
