Each tutorial is a lesson with a fixed end point. Type the commands and code yourself and compare what you see with
what the page shows. The tutorials explain very little on purpose. Once something works and you want to know why, the
[explanation]({{< relref "/explanation" >}}) pages pick up from there.

Start with the Lean tutorial. It needs only a Lean toolchain, while the benchmark tutorial also needs Rust, `uv` and
`jq`.
